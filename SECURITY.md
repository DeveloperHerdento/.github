# Security policy

This policy applies to every repository in the DeveloperHerdento organization.

## Reporting a vulnerability

Email **developer01@herdento.com** with:

- the repository and, if you know it, the file and line
- what an attacker could do
- steps to reproduce

Please do not open a public issue for security problems. We reply within 3 working days.

## Leaked secrets

If you find a password, token or API key in a repository or its history, report it the same way.
The owner **rotates the secret first**, then cleans the history.
